# GORAKHPUR 365

A mobile-first, Hindi-first local storytelling website for Gorakhpur.

## Website
- Static HTML/CSS/JS in `index.html`
- Designed for GitHub Pages
- No build step or paid dependencies
- Creator watermark: `The_Real_Suraj_🇺🇸`

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then Save. After GitHub finishes publishing, the site should appear at `https://anshikaarya639619-del.github.io/Ggfuf/`.

## Before public launch
The story-submission email currently uses a placeholder address (`gorakhpur365@example.com`). Replace it with the real inbox before inviting submissions. The site currently has no backend, database, analytics, or social account integration.
